# Employee Project Data Analysis – Python

## Project Overview

This project demonstrates the use of Python, Pandas, and NumPy to analyze and transform employee, seniority, and project data.

The analysis combines multiple datasets and applies data transformation, conditional logic, missing-value handling, merging, and aggregation to derive employee- and project-level information.

## Objectives

- Create and work with Employee, Seniority Level, and Project datasets
- Handle missing project cost values using a running average
- Split employee names into first and last names
- Combine multiple DataFrames into a single dataset
- Calculate project-based bonuses
- Apply designation changes based on project status and employee age
- Calculate total project costs for each employee
- Filter employee records based on city information

## Dataset

The project uses three datasets:

1. **Employee Data** – employee name, gender, city, and age
2. **Seniority Level Data** – employee designation levels
3. **Project Data** – project name, cost, and project status

## Project Tasks

The notebook covers:

1. Creating the three datasets and saving them as CSV files
2. Calculating missing project costs using a running average
3. Splitting employee names into First Name and Last Name
4. Joining the three datasets into a final DataFrame
5. Calculating a 5% bonus for completed projects
6. Updating designation levels based on project failures
7. Adding appropriate titles to employee first names
8. Promoting employees based on age criteria
9. Calculating total project cost by employee
10. Filtering employee details based on city names
